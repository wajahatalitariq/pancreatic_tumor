# Pancreatic CT Image-Space Delaunay Landmark Overlays, Frozen Swin-V2, and Binary HHO: Confounding-Controlled Evaluation

Official reproducible repository for:

> **Image-Space Delaunay Landmark Overlays with Frozen Swin-V2 Representations and Binary Harris Hawks Feature Selection: A Confounding-Controlled Evaluation in Pancreatic CT Classification**

---

## 1. Repository Files

- `extract_features.py`: Unified Stage 1-2 preprocessing (`Gaussian 5×5 σ=0`, `CLAHE clipLimit=2.0, tileGridSize=8×8`, `Harris blockSize=2, ksize=3, k=0.04, R > 0.02·R_max, d_nms=20 px`, `0.40×` planar Delaunay overlay) and feature extraction across all five Stage 1 control variants (`raw`, `clahe`, `clahe_dim`, `rand_mesh`, `harris_mesh`) for `Swin-V2-Tiny` (`768-D`) plus `ResNet-18` (`512-D`) and `ResNet-50` (`2048-D`).
- `run_evaluation_pipeline.py`: End-to-end confounding-controlled benchmarking across three evaluation regimes:
  - **Regime A:** Full-cohort ordered 75%/25% block split (`744` train / `248` test)
  - **Regime B:** Within-source Subgroup 1 (`source_group == 1`, `347` train / `116` test)
  - **Regime C:** Cross-source out-of-distribution transfer (`Train Subgroup 1 [463]` → `Test Subgroups {0, 2, 3} [529]`)
  - Includes end-to-end fine-tuned `Swin-V2-Tiny`, 5-seed Binary HHO Jaccard stability (`42–46`), matched-cardinality `L1`, `PCA`, `MI`, and `ResNet-18` baselines, ordered 5-fold sequence-block CV, exact McNemar + DeLong ROC-AUC + Holm-Bonferroni tests, slice-level & moving-block (`L = 10`) bootstrap 95% CIs, Bayes screening PPV estimates, and source-colored `t-SNE`.
- `requirements.txt`: Required Python packages.

## 2. Dataset Caveats & Structure

Place the curated dataset from `jayaprakashpondy/pancreatic-ct-images` under `CLEAN_DATASET/`:

```text
.
├── extract_features.py
├── run_evaluation_pipeline.py
├── requirements.txt
├── README.md
└── CLEAN_DATASET/
    ├── manifest.csv            # Deduplicated slice manifest with source_group (0..3) metadata
    ├── images/
    │   ├── normal/             # 620 normal CT PNG slices (normal_0000..normal_0806)
    │   └── pancreatic_tumor/   # 372 pancreatic tumor PNG slices (pancreatic_tumor_0807..1178)
    ├── cached_features_v2/     # Generated by extract_features.py
    └── outputs/                # Generated JSON/CSV ledgers and result plots
```

**Important Methodological Note:** The distributed dataset consists of quantized `[0, 255]` PNGs without patient identifiers, DICOM HU rescale metadata, or contrast-phase timestamps, and exhibits class-by-source imbalance across `source_group 0–3`. Patient-level volume isolation is therefore not verifiable from this compilation.

## 3. Running the Pipeline

```bash
pip install -r requirements.txt
python extract_features.py
python run_evaluation_pipeline.py
```

Key verified ledger written to `CLEAN_DATASET/outputs/`:
- `comprehensive_revision_results.json` — Complete JSON ledger containing Regime A, Regime B (`source_group 1`), and Regime C (OOD) benchmark metrics, Stage 1 control comparisons, 5-seed HHO feature counts & Jaccard stability, ordered 5-block CV metrics, slice & moving-block (`L = 10`) bootstrap CIs, Bayes screening PPV estimates, internal `85/15` hyperparameter grid results, and exact McNemar + DeLong + Holm-Bonferroni hypothesis tests.
